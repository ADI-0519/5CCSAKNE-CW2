# Contributing

## Workflow

- All changes/merges should go through the Pull Requests.
- Do not push directly to `main` or `dev` branches.
- Ensure CI checks pass before requesting review/pushing code. 

## Branch Naming

Use clear branch names such as:

- `feature/kg-schema`
- `feature/data-ingestion`
- `fix/ttl-validation`
- `docs/report-updates`

## Team Expectations

- Keep meeting minutes and prompt logs up to date.
- Document any LLM-assisted step so it can be justified in the report.
- Avoid force-pushing shared branches unless the team has agreed to it.
